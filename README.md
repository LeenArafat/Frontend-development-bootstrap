# SoftSkin

SoftSkin is a responsive e-commerce frontend landing page built using Bootstrap.  
This project focuses on creating a clean, modern, and user-friendly shopping interface using only frontend technologies.

---

## Features

- Responsive design for different screen sizes
- Modern e-commerce UI layout
- Clean and organized sections
- Bootstrap grid system
- Product showcase design
- Smooth and simple user interface

---

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
